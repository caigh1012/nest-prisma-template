## 中间件

在控制器执行前/后运行，处理 HTTP 层逻辑（如日志、CORS）

## 异常过滤器

在方法执行后运行，处理异常（如验证失败、数据库错误）并返回统一响应。

## 管道

管道有两种典型用途：

转换：将输入数据转换为所需格式（例如，从字符串转换为整数）
验证：评估输入数据，如果有效，则直接传递，否则抛出异常。

## 拦截器

在方法执行前后运行，可修改响应、抛出异常、缓存等；
